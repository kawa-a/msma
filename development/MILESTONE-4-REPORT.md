# Milestone 4: public opt-in integration

S4PCA is exposed through `msma()` using `structure.method`, `gammaX`,
`history.method`, and `niterS4`. Defaults preserve the Version 3.2 dispatcher.
Initial scope is single-matrix PCA with vector or one-column Z. Unsupported
multiblock, PLS, multivariate-Z, and NMF combinations fail explicitly.
